# return-saas — agent router

Return & refund tracking SaaS shell (Looply); portfolio demo and revival-ready. Email-intelligence unifier capability lives in In Unity (`MoneyTalks`).

**This repo must not own** new features, pricing, Stripe tiers, marketing pages, or Looply branding. Keep healthy: email/receipt ingestion, returns/refunds domain, digest queue, and security.

## One command

```
npm run check
```

Lint, typecheck, and unit test suite in ~2 seconds. **It is the checklist.** There is no other checklist.
